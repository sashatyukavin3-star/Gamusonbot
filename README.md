### 💰 Система
- Поинты за победы (5-20)
- Профиль `/profile`
- Топ-10 `/top`
- Ежедневный бонус `/bonus` +50

### 🚀 Запуск

#### 1. Локально (polling — самый простой)

```bash
cd gamebot
pip install -r requirements.txt
python bot.py
```

Бот сразу начнет отвечать в Telegram. Оставь терминал запущенным.

#### 2. На сервере (фон)
```bash
nohup python bot.py &
# или
pm2 start bot.py --name gamebot --interpreter python3
```

#### 3. В Docker
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "bot.py"]
```

### 🛠 Расширение
Хочешь добавить игру?
- Открой `bot.py`
- Найди `# --- ИГРЫ`
- Добавь новую функцию `start_mygame` и кнопку в `games_inline_kb()`
- Добавь обработчик в `callback_router`

Идеи: 2048, змейка (WebApp), морской бой, шахматы, покер, кликер.

### 📞 Поддержка
Если бот не отвечает:
- Проверь что `python bot.py` запущен без ошибок
- Проверь токен в `.env`
- Сделай `/getWebhookInfo` — должен быть пустой url (polling), иначе удали вебхук: `https://api.telegram.org/bot<TOKEN>/deleteWebhook`
